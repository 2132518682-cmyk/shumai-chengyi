# 数脉承遗 · 文物高保真数字化与轻量化展陈

文物 3D 重建的轻量化编码与端侧实时呈现。核心是把高斯泼溅模型的体积压到十分之一量级，同时保证展陈端观感与训练评估的一致性；手机浏览器打开链接即可查看，无需安装应用、无需后端 GPU。

## 定位

| 维度 | 说明 |
|---|---|
| 生产侧 | 离线完成：影像采集 → COLMAP → 3DGS 训练 → 属性量化压缩 |
| 压缩目标 | 观感优先的 8–10×，而非盲目追求最高压缩比 |
| 展陈侧 | 桌面原生 CUDA 渲染（画质基准）+ 手机浏览器端侧渲染（WebGPU/WebGL2） |
| 分发 | 静态托管，模型 3–5MB，随页面加载 |

## 技术要点

1. **属性量化压缩**：对高斯的 SH 系数、缩放、旋转、不透明度分通道量化，量化本身近乎无损（实测 8bit 全属性 PSNR 仅 -0.0002dB），体积收益来自位宽而非剪枝。
2. **观感指标**：在 PSNR / SSIM / LPIPS 之外引入背景泄漏亮度（BL），度量黑背景区域因浮空高斯产生的灰雾，解决指标与主观观感脱节的问题。
3. **端侧渲染**：渲染光栅化交由成熟引擎（three.js 原生高斯泼溅 / WebGPU），自研部分仅为压缩格式解码器，画质与稳定性由引擎保证。
4. **双后端降级**：WebGPU 不可用时自动降级 WebGL2，覆盖微信内置浏览器等受限环境。
